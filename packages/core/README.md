# @change-spotlight/core

Shared, dependency-free logic for [Change Spotlight](https://github.com/Rijja-Farhan/ChangeSpotlight):
`git diff` parsing, matching JSX elements to diff hunks, the seen model and the protocol messages
between the Vite plugin and the VS Code extension.

You normally do not install this yourself. `@change-spotlight/vite-plugin` depends on it.
